# 截图

README 里引用的截图请放在这里。**必须使用假数据或打码**（不要出现真实商户名、金额、账号、学校/单位名）。

建议准备 4~6 张（1080×2400 左右，深色或浅色任选）：

| 文件名 | 内容 |
| --- | --- |
| `01-records.png` | 明细页：柱状图 + 按日分组账单 |
| `02-stats-month.png` | 统计页（按月）：支出占比 + 分类排行 + 按天查看（展开某一天） |
| `03-category.png` | 分类账单独立页 |
| `04-settings-auto.png` | 自动记账设置：权限与状态 / Root 增强 / Hook 模块 |
| `05-profile.png` | 我的页：外观（主题 / 毛玻璃）与稳定性 |
| `06-hook-diag.png` | Hook 诊断（可打码包名外的信息） |

拍图小技巧：在真机上先**新建几笔假账单**（例如「测试商户 12.34 元」），或直接用应用里的"金额隐藏"再截图。
