# 排障手册

按"症状 → 排查步骤"组织。90% 的问题用**运行日志**就能定位：
「我的 → 稳定性 → 运行日志 → 保存到下载」，文件在 `下载/简记/`。

---

## 1. 完全不记账

1. 看「自动记账设置 → **识别记录**」：它会说明"识别到了什么、为什么没记"（同一条通知已记过 / 方向不明 / 被拦截词拦下…）；
2. 看「自动记账设置 → 权限与状态」：无障碍、通知使用权、短信、通知权限是否都是 ✅；
3. 看总开关是否开着（关掉后所有采集都不跑）；
4. 三条通道至少留一条：
   - 无障碍：系统设置里「简记」的无障碍服务是否在运行（**部分 ROM 会自动关闭它**）；
   - 通知使用权：授予后才会收到 `onNotificationPosted`；
   - LSPosed Hook：见第 2 节。

---

## 2. Hook 模块显示"未生效"，但 LSPosed 日志里有 `[简记]`

**说明模块其实在工作**（能拦到通知就是证据），只是状态判定没拿到心跳。本项目已改为：

- 任何来自模块的广播都算"存活"；
- 每条转发的通知自带存活标记；
- `system_server` 每 5 分钟周期心跳。

如果你看到过"明明在记，却显示未生效"，请**导出日志**（里面会写每次状态判定的参数）。

检查清单：

1. LSPosed → 模块 → 简记 → 是否**启用**；
2. **作用域**：至少勾选「系统框架」+ 微信 / 支付宝（推荐应用已内置 81 项，可全选）；
3. 勾选后**要重启对应应用**（微信需要完全退出再打开，或重启手机）；
4. Zygisk 是否正常（LSPosed 依赖 Zygisk / Zygisk Next）。

---

## 3. 只有打开应用时才补记（后台被杀）

这是 ROM 省电策略导致的，不是记账逻辑问题：

1. 打开「自动记账设置 → Hook 模块 → **保持后台常驻**」（有活干时才常驻，不白耗电）；
2. 系统设置里给简记：**自启动** + **电池无限制** + **显示在其他应用上层**；
3. 最近任务里给简记**加锁**（MIUI/HyperOS/ColorOS 都有）；
4. 「我的 → 稳定性 → **系统放行设置**」可以一键跳到这几个设置；
5. 「高级修复」里可授权 ADB（`WRITE_SECURE_SETTINGS`），让无障碍被系统关闭后**自动恢复**。

---

## 4. 某个 App 不记账

1. 先在「识别记录」里确认**有没有收到该 App 的通知**：
   - 收不到 → 该包名没在接管名单里（加平台见 [CONTRIBUTING.md](../CONTRIBUTING.md)）；
   - 收到了但没记 → 解析没识别出金额/方向，请把通知原文（可打码金额）提 issue；
2. 银行类：部分银行 App 只发短信不推送 → 走短信通道，需要 `RECEIVE_SMS`；
3. 信用卡通知常带「可用额度」：本项目已专门处理（不能被额度数字带偏，也不会因为出现"额度"就整条丢弃）。

---

## 5. 记账金额不对

- 通知里同时出现多个金额时（消费 / 可用额度 / 余额），会跳过「余额、可用额度、剩余、限额、总额、积分」后面的数字，取真正的交易金额；
- 如果仍不对，请提供**通知原文**（金额可打码但保留位数）与该笔在应用里的显示。

---

## 6. 打开毛玻璃后卡顿 / 黑屏（历史问题，已修）

- 早期版本用 GPU 实时模糊（`RenderEffect`），在部分 ROM 上会黑屏 → 现在改为**纯软件一次性模糊**（小尺寸 + 双向过滤放大），内存约 1MB；
- 如果仍然异常：设置里关掉毛玻璃即可（不影响记账），并请附带机型与 ROM 版本提 issue。

---

## 7. 应用打不开 / 闪退

1. 先去「**文件管理 → 下载/简记**」找 `简记崩溃-*.txt` —— 崩溃堆栈会写在那里，把它发到 issue 里；
2. 再打开一次应用：如果上次启动没进主界面，本次会自动进入**安全模式**（跳过毛玻璃等可选功能），通常就能打开；
3. 还是不行：请用与之前**相同来源**的 APK 覆盖安装（不同签名的 APK 不能互相覆盖）；
4. 卸载重装会清空本地账本，**请先导出备份**。

---

## 8. 数据与备份

- 所有数据在应用私有目录（`jianji.db`），**跟着应用卸载一起删除**；
- 定期「我的 → 备份与导出 → 导出 CSV/XLSX」保存到手机或电脑；
- 应用**没有云同步**（刻意不联网），换机请用导出文件。

---

## 9. 提交 issue 时请附上

1. **运行日志导出文件**（`设置 → 运行日志 → 保存到下载`，或直接复制文本）；
2. 机型 + ROM 版本 + Android 版本；
3. 触发路径（哪个 App、做了什么操作）；
4. 期望结果与实际结果。

> 日志已刻意**不含金额与商户**，可以放心附上。
